# Security

Mixpilot has access to the sound apps play (the System Audio Recording permission) and can turn the
microphone off. If you find a way this could be misused, or any other security problem, please
report it privately:

- on GitHub: [Report a vulnerability](https://github.com/ahmedmaaloul/Mixpilot/security/advisories/new), or
- by email: support@blitzraum.com

Please don't open a public issue for it. You'll get an answer within a few days. Only the latest
version of Mixpilot receives fixes.
